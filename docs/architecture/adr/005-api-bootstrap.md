# ADR-005 — Bootstrap mínimo e migração para framework modular

Status: temporário, complementado pelo ADR-006. A API usa HTTP nativo TypeScript com módulos de domínio. JWT OIDC, banco e IdP reais foram verificados no desenvolvimento. A migração para NestJS modular segue como avaliação antes de staging, com paridade de segurança e contratos. Readiness, telemetria e demais critérios de Sprint 0 continuam abertos. Alternativa descartada: prometer controllers Nest e rotas reais sem instalação/execução verificadas.
